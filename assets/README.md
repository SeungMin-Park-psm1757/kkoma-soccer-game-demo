# 그림 자산 위치

- `players/`: 공통 체형의 투명 WebP 선수 스프라이트. `manifest.json`의 `idle`, `run`, `kick` 배열에 파일명(예: `base-idle.webp`, `base-run-1.webp`)을 넣으면 로드된다. 프레임은 같은 크기와 중심점을 사용하고, 유니폼을 그리는 캔버스 레이어 아래에 놓인다. 파일이 없거나 로드에 실패하면 기존 캔버스 선수가 표시된다. 권장 원본 크기는 최대 128×136px이다.
- `kits/`: 향후 국가별 패턴 또는 마스크. 현재 색상은 `game.js`의 국가 데이터가 그린다.
- `stadium/`: 향후 경기장 배경. 게임 좌표와 충돌 판정은 `game.js`의 `project`/`unproject`와 분리한다.
- `ui/`: 향후 버튼·아이콘.

추가 애니메이션 상태 `shoot`, `receive`, `celebrate`는 그림이 준비되면 같은 프레임 규격으로 확장한다. 실제 협회 엠블럼과 스포츠 브랜드 로고는 사용하지 않는다.
