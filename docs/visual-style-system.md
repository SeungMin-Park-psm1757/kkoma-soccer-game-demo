# 꼬마 축구 월드컵 비주얼 시스템

## 진단

- 메뉴·연습·팀 선택은 같은 초록색 계열이지만 패널, 타일, 버튼의 테두리와 그림자 규칙이 서로 달라 한 화면 세트처럼 보이지 않았다.
- 기본 국가 선수는 머리·상의·다리가 단순한 분리 도형이라 작은 화면에서 팔다리와 표정이 잘 읽히지 않았다. 대한민국 스프라이트와 다른 국가의 Canvas 표현도 인상이 달랐다.
- 잔디색이 거의 단일 평면이고 골대와 공의 명암이 약해 플레이 공간의 깊이와 작은 오브젝트의 대비가 부족했다.
- 경기장 콘셉트 원본은 2.1MB이며 현재 원근 좌표/필드 선과 일치하지 않아 배경으로 바로 적용하면 선수가 경기장 라인과 어긋날 수 있다.

## 스타일 규칙

- **색:** 깊은 숲색 `#073d35`를 바탕으로, 민트 하이라이트 `#9af0d2`, 라임 `#d5f56b`, 따뜻한 골드 `#ffe58c`를 강조색으로 사용한다. 국가별 kit 색상은 유지한다.
- **버튼:** 둥근 모서리와 밝은 상단 하이라이트, 짧은 바닥 그림자를 공유한다. 라임은 주요 행동, 금색은 보조 행동, 투명 유리색은 뒤로/메뉴 행동이다.
- **카드:** 녹색 계열의 얕은 2.5D 그라데이션, 가는 민트 테두리, 공통 둥근 모서리와 부드러운 그림자를 사용한다.
- **캐릭터:** 7개의 AI 생성 공통 포즈(idle/run/pass/shot/tackle/GK idle/GK save)를 모든 국가에서 재사용한다. 옷 마스크가 상의·하의·양말만 TEAM_PROFILES 키트 색으로 바꾸고 얼굴·머리·신발·흰색/네이비 장식은 원본 픽셀을 유지한다. 경기별 홈/원정 키트를 사용하며, 로드 실패 시 대한민국은 기존 WebP, 다른 팀은 기존 Canvas 렌더러로 돌아간다.
- **경기장:** 필드 좌표를 바꾸지 않고 잔디에 약한 세로 깊이 그라데이션과 기존 mowing stripe를 사용한다. 라인은 밝은 얇은 획과 희미한 외곽광, 골대는 짙은 받침선과 밝은 프레임으로 구분한다.
- **공·아이콘:** 공은 흰 바탕, 짙은 패널, 작은 하이라이트로 작은 크기에서도 읽히게 한다. 메뉴의 기존 SVG 로고와 이모지 안내는 간결한 보조 아이콘으로 유지한다.
- **텍스트:** 기존 한국어 폰트 fallback과 제목 계층을 유지한다. 짧은 라벨은 밝은 배경 대비를 높이고, 본문은 흰색/연민트로 표현한다.
- **효과:** 현재 이동·패스·슛·골 판정은 그대로 두고, 잔디·라인·버튼의 명암으로 강조한다. 무거운 파티클과 새 애니메이션 자산은 추가하지 않는다.

## 적용 범위

전역 CSS 토큰으로 메뉴, 팀 선택, 조작 연습, HUD, 결과 및 엔딩의 카드/버튼 계열을 맞춘다. 메뉴 키비주얼과 대한민국 경기 캐릭터에는 실제 생성된 AI 이미지 자산을 사용한다. Canvas의 필드, 골대, 공, 일반 국가 선수 fallback만 가볍게 다듬고, 게임 좌표계는 유지한다.

## 국가별 공통 캐릭터 적용

- `assets/players/manifest.json`의 `commonArt`가 공유 7개 포즈와 `assets/players/national-kit-mask-v1.png`의 행 배치를 정의한다.
- 마스크 아틀라스는 셀당 128×136이며 RGB 채널이 각각 상의·하의·양말 영역을 가리킨다. `python scripts/build-national-kit-mask.py`로 재생성하고 `--check`로 원본 포즈와 일치하는지 확인한다.
- 브라우저는 공통 WebP 7개와 단일 마스크만 사용한다. 경기 중 색상 변형 Canvas는 홈·원정 두 키트만 상태별로 캐시하며, 새 경기를 시작하면 캐시를 비운다.
- 색상 변환에서 마스크 밖의 원본 픽셀과 알파를 보존한다. 이미지/마스크 처리 실패 시 기존 대한민국 WebP 또는 Canvas 캐릭터를 사용한다.
- 390×844 캡처에서 캐릭터 실루엣이 작게 읽혀 스프라이트 그리기 상자만 가로·세로 약 8% 키웠다. 월드 좌표, 충돌 반경, 터치 판정, 카메라, 그림자와 공 크기는 바꾸지 않았다.
